# MNN Basic Example

基础示例：检测 MNN 库是否正确加载并显示版本信息。

## 使用方法

1. 在 Unity 中打开 Package Manager
2. 找到 MNN for Unity package
3. 展开 Samples 部分
4. 点击 "Import" 导入 Basic Example
5. 打开 `Scenes/BasicExample.unity`
6. 运行场景

## 期望结果

- 控制台显示 "✓ MNN loaded successfully!"
- 控制台显示 MNN 版本信息
- 场景中显示绿色状态文本

## 支持平台

- ✅ iOS (Metal backend)
- ✅ Android (OpenCL backend)
- ✅ macOS (Metal backend)
- ✅ Windows (CPU/CUDA backend)
- ✅ Linux (CPU/CUDA backend)
- ✅ WebGL (WebAssembly backend)
