# SiriAI 视听设置与人员管理

系统设置中的“对话”直接提供“模型判断退出对话意图”和“验证语音输入”，无需先展开高级音频设置。
“人员管理”独立集中管理本机已录入的人员、姓名、人脸预览和交互权限。
“视觉”负责摄像头、画面上下文、人脸交互权限和视听融合拾音；
“音频 → 高级音频设置”负责回声/降噪、语音开始与结束、参考声纹提取、多人重叠分离、
声纹交互权限和唤醒词。音频与视觉的数值选项通过预设选择，不要求输入模型路径或人员 ID。
视听提取、参考提取、分离和声纹模型复用现有模型选择器；下载成功并通过完整性检查后才修改草稿。

人脸交互权限集中在一个“实时语音交互权限”选择中，旁边就是模型选择与人员管理：

| 模式 | 保存后的效果 |
| --- | --- |
| 镜头内任何人 | 检测到人脸后可开启实时语音；离开画面暂停新的收音；保留已设定的禁止规则。 |
| 镜头内目标说话人 | 自动选择突出、相对较近且居中的人脸；只有该目标的唇动、朝向和音频联合符合条件时才形成实时语音输入；无需预先注册。 |
| 仅已录入人脸 | 只允许已录入并设为允许的人脸开启实时语音；陌生人暂停收听，允许名单为空时保持暂停。 |

这些模式针对实时语音；文字与按住说话不附加自动视觉门控。
已有禁止人员在三个模式中都保留，页面会明确提示；进入“人员管理”解除禁止或删除记录。
目标模式按检测置信度、人脸面积和画面中心位置排序，以 IoU 与中心/尺度连续性保持跟踪，明显更强的候选人
需持续 600ms 才切换；当前目标有说话证据时保持焦点。人脸面积只是相对距离的代理，
不是深度测量。几何匹配含糊或交叉时拒绝任意指定目标。

联合 VAD 位于音频 VAD 之后、端点判定与 ASR 之前，使用同一目标、同一采集时钟的证据：

- SCRFD 五点朝向以双眼轴归一化鼻尖的水平偏移，正面范围使用平台区、明显左右转头才逐渐衰减；低头、抬头和侧倾不再直接降低朝向分数。这是粗略头姿代理，不是眼球注视或标定后的三维头姿。
- 112×112 对齐人脸先用上脸估计 ±4 像素的整体平移并扣除亮度变化，再要求嘴部残差超过上脸与两侧脸颊残差；避免把整体移动当作唇动。
  500ms 内至少两帧有效唇动、最近运动不超过 300ms 时保持说话态；视频新鲜度容忍 320ms，朝向证据容忍 750ms，支持适度低帧率与短音素停顿。换目标和陈旧证据会清除或拒绝复用。
- 只有音频 VAD 和目标视觉活动同时成立才启动目标轮次。保留原始前滚，
  目标开始后旁人独自说话的帧变成等长静音，保持采样时钟，让端点能及时结束。
- 随后复用已有视听提取模型，在完整语句上提取目标声音；不等于逐帧实时说话人分离。

唇动阈值与朝向阈值仍是几何/像素启发式，尚未通过实拍数据标定精度；静态图片测试与管理层测试
不能证明真实重叠说话的分离准确率。画面太慢、遮挡或不同步时会暂停目标模式的收听。
纯声音模式仍默认逐轮自动选人；同一轮稳定，下一轮可以换人，无法区分时拒绝。

需要限制交互时，在“人脸交互权限”或“声纹交互权限”点击“添加人员”。
人脸向导分为准备、三秒倒计时采集和确认，要求画面中只有一张人脸；
声纹向导通过现有麦克风采集所有者录制四秒。预览保持宽高比并处理摄像头旋转、镜像，
横屏与小屏限制卡片高度，关键说明前置，正文可滚动而主要操作固定。
采集完成展示实际编码的帧，可重新采集、取消或确认加入草稿；动画遵守减弱动态设置。
录制不会转写或发送给 AI。保存本机模型相关特征及实际对齐人脸的 PNG 缩略图，不保留原始全幅照片或原录音；向导明确告知缩略图用途。
录入完成进入独立“人员管理”页；每人可命名（1–64 字符）、预览、单独补录/更新人脸或声纹，以及允许、禁止或删除。
姓名与缩略图随身份快照及设置持久化，旧人员显示默认名称和占位图；关闭页面释放预览纹理。删除人员同时删除其缩略图。
点击设置页“保存”才生效，取消则丢弃草稿。
禁止规则优先于允许名单；删除最后一个允许人员不会自动放开交互限制。
切换身份模型后需要重新录入，旧模型的向量不会用于新模型。

`MNNInteractionSettings.automaticSpeakerSelection` 默认启用；显式关闭可保留旧的固定目标策略。
`identities` 保存 `MNNInteractionIdentity`，`voiceRecognition` 控制声纹允许名单，
`faceRecognition` 与 `allowedIdentities` 控制人脸允许名单，`allowed=false` 表示禁止。
只启用摄像头不会隐式要求声音目标必须拥有同步画面；只有视听提取使用同步画面。
旧的 Presence 构造函数与 Configure 方法保留，通过新增重载提供禁止名单。

实时语音的端点静音窗口保持原采样时钟，不再因尾段没有目标声音丢弃整句。
等待目标处理或端点识别期间，缓冲满后的纯静音只推进静音预算，不增长 PCM 或改变当前句子的修订号；
真正的连续说话超出容量仍拒绝截断句子。这样不会把等待识别的尾部静音误当作超长语音并丢掉请求。
可取消的轮次模型超过最大静音预算时，取消本次端点推理并继续声纹/语音验证；
外层取消、说话恢复、采集缺帧仍保留既有中止策略。自定义 provider 必须遵守 CancellationToken。

验证使用共享管理代码与模型替身，覆盖端点提交、静音、新说话人、交互名单、录制所有权、
页面分类、选择器和中文提示。未新增模型、原生桥、C++ 代码或官方 MNN 修改；
新增控制流回归覆盖“目标安静而旁人说话不提交”“目标说话只形成一轮”及
“目标停止后旁人继续说话，目标轮次仍结束”。226 项管理层回归通过、2 项因缺少本地模型跳过；
另有横竖屏与小屏中文引导渲染检查。这些回归不构成真实麦克风/摄像头、
重叠语音分离准确率或官方 C++ ABI 的验证。
