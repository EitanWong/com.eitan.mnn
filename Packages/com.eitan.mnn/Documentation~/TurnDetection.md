# 轮次检测与延迟

实时会话先用 VAD 确认语音和停顿，再调用轮次检测器。`silenceMilliseconds`（默认 550 ms）是首次送检的静音门槛，`turnRetryMilliseconds`（默认 500 ms）控制否定结果后的重试间隔。

`MNNConversationOptions.maximumTurnSilenceMilliseconds` 默认 2000 ms：连续 VAD 静音达到这个上限时，停止等待语义模型的否定结果，进入原有的语音校验和提交过程。有效上限至少等于 `silenceMilliseconds`。恢复讲话会重新计算静音时间；录音丢帧与容量溢出仍拒绝提交残缺语句。该选项不限制模型推理、ASR 或语义校验耗时。较长的上限适合长思考停顿，较短的上限降低等待，但会增加在句中停顿时提前提交的风险。

送检快照只保留最多 800 ms 的末尾 VAD 静音，保留语音和句中停顿。持续静音不会在重试时将语音挤出 SmartTurn 的八秒上下文，也不会让 ASR 反复处理不断增长的尾部静音。原始录音快照接口保持完整音频。

确定性回归覆盖首次肯定、持续否定、重试尾部静音、恢复讲话与兜底校验。该验证证明会话调度行为，不代表模型在真实麦克风数据上的准确率。
