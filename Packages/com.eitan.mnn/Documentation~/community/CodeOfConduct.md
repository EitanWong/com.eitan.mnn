# Community guidelines

Treat contributors and users respectfully. Critique code and ideas with specific,
constructive feedback. Welcome people with different backgrounds and experience.
Harassment, discriminatory remarks, threats and disclosure of another person's
private information are not acceptable.

These expectations apply to issues, pull requests and other project spaces.
Maintainers may edit or remove inappropriate content, close discussions or
restrict participation when necessary. Report a concern to the repository owner
through an available private channel; avoid repeating sensitive details publicly.
